# ARROWS X — Puzzle Escape

Tap the arrows to slide them off the board. Clear every arrow without getting blocked.

A single-file HTML game (canvas), installable as a PWA and packaged as an Android APK.

**Made by** Gopu / RYÚK ZÉRÖ

## Run it

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole game |
| `manifest.webmanifest` | PWA manifest (name, colours, icons) |
| `sw.js` | Service worker for offline play |
| `icon-*.png` | App icons (regular and maskable) |
